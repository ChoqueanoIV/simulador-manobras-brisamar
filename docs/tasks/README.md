# Tasks

Esta pasta contém as tarefas de implementação do Simulador de Manobras do Pátio Brisamar.

A fonte principal de priorização é:

- `../BACKLOG_MVP.md`

As tasks individuais poderão ser criadas aqui conforme o desenvolvimento avançar.

Formato recomendado:

```text
TASK-001-fundacao-projeto.md
TASK-002-canvas-svg-patio.md
TASK-003-zoom-pan.md
...
```

Cada task deverá conter:

- contexto;
- objetivo;
- escopo;
- critérios de aceite;
- fora de escopo;
- testes esperados;
- dependências;
- evidências necessárias.
